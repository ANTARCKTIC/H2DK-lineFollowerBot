# H2DK-lineFollowerBot

Welcome to the H2DK line following bot project! This repository will contain the code and documentation for building a line-following robot using Arduino to compete in the upcoming ESPRIT RAS ROBOTS 2.0 .

## Overview

The Line Follower Arduino Bot is a robotic project designed to autonomously navigate along a predefined path by following a visible line on the ground and getting through complicated challenges. Leveraging infrared sensors , ultrasonic sensors and a PID-based control algorithm, the robot can make real-time adjustments to its motor speeds, ensuring precise tracking of the line and smooth traversal through intricate paths.

### Key Features

- **Autonomous Line Following:** The robot is capable of autonomously following a line on the ground, making it suitable for applications such as maze-solving or tracking courses.

- **Infrared Sensors:** The project utilizes infrared sensors to detect the contrast between the line and the surrounding surface, enabling the robot to make accurate navigation decisions.
- **Ultrasonic Sensors:** In certain parts of the track the robot is going to use Ultrasonic sensors to detect and avoid walls and navigate through a tunnel 
- **PID Control for Motor Adjustment:** A Proportional-Integral-Derivative (PID) controller is employed to dynamically adjust the motor speeds, providing a fine-tuned response to keep the robot centered on the line.

- **Hardware and Software Integration:** This project serves as an excellent example of integrating hardware (motors, sensors) with software (Arduino code) to achieve a specific robotic behavior.
